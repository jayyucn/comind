## What was done

### Test script debug + fix

Created `D:\tmp\_tw_merge2.py` (merged persistence E2E test). Found and fixed two issues in the test itself:

1. **Wrong selector** — test used `.block-content[contenteditable=true]` and `.ProseMirror.nth(1)`. ProseMirror inside Editor is inside `.editor-wrapper` (not a direct child of `.block-content`), and only ONE Editor exists at a time (single editor principle). The correct approach: `.ProseMirror.first` always targets the active block's Editor.

2. **Cursor position for merge** — pressing Backspace only triggers merge when cursor is at position 0. After typing 'World' in the new block, cursor is at the END. Added `page.keyboard.press("Home")` to move cursor to start before Backspace.
