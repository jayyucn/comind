### 关键实现细节

**handleConfirm**（composable 内）：
```ts
function handleConfirm(value: DateTimePickerConfirm) {
  const editor = editorStore.activeEditor
  const state = editorStore.dateRefEditor
  if (!editor || !state) { close(); return }
  const newText = serializeDateRef({ kind: value.kind, iso: value.iso, recurrence: value.recurrence })
  editor.chain().insertContentAt({ from: state.from, to: state.to }, newText).run()
  close()
}
```

**为什么用 `insertContentAt` 而非字符串 replace**：
- 编辑态下 content 是 ProseMirror doc，from/to 是 PM 文档坐标
- `insertContentAt({from, to}, text)` 精确替换该区间，与 PM transaction 集成
- Decoration 随 PM doc 重渲染（无需手动更新 decoration set）
