# QueryToolbar 搜索按钮改为可收起开关

`QueryToolbar` 的搜索从「常驻输入框」改为「图标按钮 + 可收起输入框」：默认仅显示 🔍 图标按钮；点击后输入框**从右向左展开**（`width` 200ms + `opacity` 过渡，右端固定在按钮左侧、左端随宽度增长），并自动聚焦；再次点击搜索按钮、或点击筛选/排序/分组任意按钮时，输入框收起（已输入的 `searchQuery` 保留，不清除）。

**权衡**：常驻输入框更易于发现、但常占 200px；可收起更整洁、顶栏聚焦「筛选/排序/分组」主操作，代价是搜索入口需先点开（发现性略低）。页面库顶栏以筛选/排序/分组为主操作、搜索为辅助，故选可收起。

筛选/排序/分组 三按钮图标沿用 currentColor（常态 `text-tertiary`、hover `text-secondary`、激活 `accent`），本次仅固化记录，**无功能改动**。详见 `CONTEXT.md` 的 QueryToolbar 词条。
