### 迁移逻辑

遍历所有页面 → 所有 block → 检查 deadline/scheduled/recurrence 属性：

| 迁移前 | 迁移后 |
|--------|--------|
| `properties: { deadline: '2026-07-20' }` | `content: '{{deadline:2026-07-20}} 原有内容'` |
| `properties: { scheduled: '2026-07-15', recurrence: 'weekly' }` | `content: '{{schedule:2026-07-15|weekly}} 原有内容'` |

### 特性

- **幂等**：content 已含 `{{deadline:…}}` 或 `{{schedule:…}}` 的 block 跳过
- **容错**：单个 block 迁移失败不中断整体流程
- **空内容**：content 为空时 dateRef 作为全文
- **已删除属性**：`is_deleted=1` 的属性跳过
- **纯数据层**：不依赖 Pinia/Vue，直接使用 CoreClient

### 测试

10/10 通过，覆盖：无页面、单属性、属性+recurrence、幂等跳过、空内容、无日期属性跳过、多页面、异常容错、格式报告、已删除标记。

### 调用方式

