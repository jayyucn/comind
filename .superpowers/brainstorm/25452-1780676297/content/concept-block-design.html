函数式编程
Functional Programming
概念
01 · 核心定义

一种将计算视为数学函数求值、避免状态变更和可变数据的编程范式。

02 · 边界范围
✓ 外延
  • 纯函数设计
  • 不可变数据流
  • 声明式数据处理
✗ 禁区
  • "用函数写代码"≠FP
  • 函数式≠性能差
  • 不等同于 Haskell
03 · 对标辨析
函数式
描述「是什么」
VS
命令式
描述「怎么做」
函数式
数据不可变
VS
面向对象
状态可封装修改
04 · 实例与应用
正向实例
1. [1,2,3].map(x => x*2) — 纯变换，无副作用
2. React 组件 — props → UI，输入决定输出
3. SQL 查询 — 声明「要什么」而非「怎么取」
落地用法
• 数据管道处理 — 用 map/filter/reduce 替代 for 循环
• 状态管理 — Redux 的 reducer 就是纯函数
• 并行计算 — 无共享状态 → 天然线程安全
设计要点
  • 四区折叠 — 每个区域可独立折叠/展开，核心定义默认展开
  • 色彩编码 — 定义=琥珀、边界=绿/红、辨析=靛蓝、实例=紫，一眼区分
  • VS 对比卡 — 辨析区用左右对比卡，差异点一目了然
  • 绿红分栏 — 边界区外延/禁区并排，正反对照
  • 融入 Block 体系 — 作为新 block type，通过 /concept 触发
