## 编译检查规则

### 规则要求
所有代码修改必须经过严格的编译检查，确保修改后的代码在当前项目指定的编译环境中能够成功编译。

### 执行步骤
1. **提交前检查**: 开发人员在提交代码前必须执行完整的编译流程
   ```bash
   npm run build
   ```

2. **验证编译结果**: 确保编译过程不产生任何语法错误、类型错误或依赖错误

3. **代码审查确认**: 在代码审查过程中再次确认编译状态

### 适用范围
- 业务逻辑代码（`.ts`, `.vue`）
- 配置文件（`.json`, `.tsconfig.json`）
- 测试代码（`.test.ts`, `.spec.ts`）

### 检查标准
- ✅ TypeScript 类型检查通过（`vue-tsc -b`）
- ✅ Vite 构建成功（`vite build`）
- ✅ 无语法错误
- ✅ 无依赖错误
- ✅ 测试通过（`npm run test`）

### 违规处理
未通过编译检查的代码不得提交到版本控制系统。
