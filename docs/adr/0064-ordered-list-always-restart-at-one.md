# 0064 有序列表序号段统一从 1 起

- Status: accepted
- Date: 2026-11-24
- 关联: ADR-0062（本 ADR 取代其 D2/D3 的段首起点与锚点）、ADR-0025（块复制粘贴）、ADR-0046（撤销历史）

## Context

ADR-0062 用「段首字面作起点 + `format.olIndex` 锚点」实现了「前面不动、允许断点」：段内手写跳号（`1, 10, 11`）落成锚点，段首从几开始就一直是几。

这套组合叠加了三份真相（字面、段首字面起点、锚点），带来三个问题：

- **同段序列依赖编辑历史**。同一个列表在不同时刻显示 `1, 10, 11` 还是 `1, 2, 3`，取决于历史上有没有人改过中间某一位；读的人无法在不追溯历史的情况下确认「这是第几项」。
- **锚点有四份维护责任**。写入（手写跳号）、清除（手写回自然值）、删段首时给接替者打 1、跨父搬移时清锚，分别落在 content 更新、删除、缩进/反缩进、拖动四条入口上；新增任何一条结构入口都要记得清锚，漏一处就留下无法解释的断号。
- **规则自相矛盾**。手写 `10.` 会被保留成断号，同样数字粘贴进来却一律重排；「支持断号」只对手写成立。

## 决策

### D1 段首恒 1，段内严格 +1

段 = 同一父块下**连续**的有序列表块。段首起点恒为 1，段首字面不参与推导；段内逐项 `desired = cursor`、`cursor += 1`。手写的 `5. `、段中跳号 `1, 10, 11` 一律改写为顺排。

### D2 透明块

非文本块（code / image / table / query / embed）与高亮块（`format.callout`）既不**打断**段、也不**占号**：段跨过它们继续 1, 2, 3。高亮块自身若带 `N. ` 前缀，字面原样保留为普通文本 —— 不改写、不参与序列。

理由：取消锚点后，「被一个代码块打断就永久回 1」将没有任何补救手段。视觉强调不是列表结构，不该改变编号。

### D3 边界仍是无序列表 / 标题 / 正文 / 空文本块

这四类依旧断段。空段落是读者可见的分隔，新列表自然从 1 起；若把空块也算透明，退出列表后另起一个列表会接上旧号。

### D4 归一作用域 = 被碰到的父组

一次操作只归一它碰到的父组（同父一组），不做整页扫描。段首恒 1 之后，整页扫描会把页面上每个非 1 起头的段都判成「该改」，一次编辑就重写全页列表。各入口的父组来源：

| 入口 | 作用域 |
|---|---|
| 内容变化（打字 / 斜杠 / 粘贴文本） | 本块的 `parentId` |
| 缩进 / 反缩进 | 新旧两个父块 |
| 删除 | 被删块的 `parentId`（删除前记录） |
| 粘贴 / 跨页搬移 | 落点父块 |
| 拖动 | `changed` 块的现父块 + `affected.gained/emptied` |

### D5 存量数据

`format.olIndex` 不再读写；写回路径顺手删除该键，不做迁移。存量段落打开时不改写，第一次被上述入口碰到时整段归一。正在编辑的块仍跳过写回（沿用 ADR-0062 D4）。

## 理由

- 序号是给人读的计数，不是内容标识。起点由上下文决定时，读者无法确认序列，序号就失去了作用。
- 锚点的维护成本按「结构入口个数」增长，而序号本身只需要一条纯函数。删掉锚点后，规则可以用一句话描述，且与复制/粘贴/搬移的行为一致。
- 透明块让「取消锚点」不牺牲续号能力：结构上的非列表内容不再切断序列。

## 已否决的方案

- **保留锚点、只禁止新写跳号**：`olIndex` 变成只在存量段生效的遗留字段，规则出现两个世界（老段允许断号、新段不允许），无法用一句话描述。
- **段首字面永远作起点**（删锚点但保留「从 5 开始」）：手打 `5. ` 起头仍是 5,6,7，与「段从 1 开始」直接矛盾；且新段与存量段行为相同，没有判据可区分。
- **段首也强制 1 且打开页面即全页归一**：加载路径写库，改动没被打开过的段落，与「加载不改内容」冲突。
- **排序时直接改写活动块（写 store）**：会被编辑器 300ms 后的防抖保存整段覆盖，改动无效且会闪；已否决，改为失活后对齐。
- **只改显示、不回写 content**：渲染态与编辑态前缀会各显示一套数字，查询预览与导出读的是字面，两处真相。

## 后果 / 待办

- 一次编辑会静默改写该段内所有非顺排的序号（含 `inlineMarks` / `renderSegments` 平移），无提示；同一整页快照内可一步撤销（ADR-0046 不变）。
- 活动块在失活前保留字面，可能与同段其它项重号或乱序，失活后由下一次排序对齐。
- 列表中间插入空段落，下半段回到 1。
- 高亮块保留的 `N. ` 字面可能与相邻项重号。
- 从外部粘贴/导入的编号列表一律重排为 1..n。
