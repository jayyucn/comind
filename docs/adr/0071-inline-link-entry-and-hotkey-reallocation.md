# 0071 块正文的外链写入口与 Ctrl+K 重分配

- Status: accepted
- Date: 2026-11-28
- 关联：ADR-0067（markdown 外链 chip 与视图归属）、ADR-0069（外链打开与点击）

## Context

外链在正文里已经全链路可用：Rust `render_segment_service` 产出 `ExternalLink` 段、前端渲染 chip、点击走系统浏览器（0069）、悬浮条可编辑与移除、键入裸网址与粘贴自动成 chip（0067 D6/D10）。缺的是**反向的一条路**：已经存在的一段文字，选中后加链接。

现有的三个入口都要求「先有 URL、再有链接」——键入、粘贴、`/web` 命令。用户手里的顺序常常相反：先写好了「飞书文档」四个字，回头才想让它指向某个地址。此时唯一的办法是记住 markdown 语法手打 `[飞书文档](url)`，或者把链接打出来再改别名。

选区浮层里已经有对称的**内链**入口（`[[页名]]`，Brackets 按钮），外链没有对应项。两个方向的入口一个有一个没有，是这套浮层最明显的形状缺口。

同时 `Ctrl+K` 被全局搜索面板占用（`useGlobalHotkeys`）。加链接是「选中文字 → 加链接」这一动作的行业惯例键位，被搜索占着，这条路径就只能靠鼠标。

## 决策

### D1 外链 `[文字](url)`，内链仍归 Brackets

新按钮只做外链。`[[页名]]` 已有独立按钮，两者语义不同（一段文字 vs 一个页面实体），不合并。

### D2 按钮插在 `SelectionMarkRow` 公共段内、行内代码左侧，由 `link` 三态门控

顺序：`对齐▾ | B I U S 🔗 <> A | 结构项`。图标 `Link`，`aria-label="添加链接"`。

`SelectionMarkRow` 的既有约定是「公共段在正文浮层与表格选区浮层之间必须同序同形」，这一项是**该约定的唯一例外**：新增 `link` prop（`null` = 不渲染），只有正文浮层传值。原因是表格宿主尚未实现链接写回（单元格内容同样是 block.content，但判据与写回路径要单独补）——先长出一个点不动的按钮比不长更糟。

**待办**：表格宿主接上写入后，把门控放开，同时撤掉这条例外注释，公共段恢复严格同形。

### D3 取 URL：二级浮层双输入框，标题预填选区文字，URL 预填剪贴板

- 标题框预填选区肉眼可见的文字，可改；
- URL 框在剪贴板内容能抽出 http(s) 链接时预填，读不到（无权限 / 无剪贴板）静默留空；
- 粘贴整段带文字的内容时抽**首个** http(s) 片段，其余丢弃；
- 只接受 http(s)：缺协议补 `https://`，`javascript:` / `mailto:` 一律不认（`openExternalUrl` 只放行 http(s)，写进去也是死链）；
- Enter 应用，Esc 只关二级浮层（`FloatingSubmenu` 的既有口径）。

校验与字面拼装的单一实现在 `utils/inline-link.ts`：`linkTitleRejectionHint` / `extractHttpUrl` / `buildInlineLinkLiteral`。

标题判据**不复用**页名判据 `validatePageName`：那边禁 `|`（别名分隔符）与换行（`[[ ]]` 边界），这些在链接标题里都合法。链接标题只禁 `[` `]` —— 那是 RE_MD_LINK `([^\[\]]+)` 的硬边界，含了就整段不匹配、静默断链。

裸域名抽取要排除「被更长串包住」的情况：`mailto:a@b.com` 里的 `b.com` 不是域名，`a.feishu.cn` 也不该被抽成 `a.feishu.cn` 之外的东西。判据是前一个字符不是 ASCII 词元（`[A-Za-z0-9@._-]`）。

### D4 能力边界沿用「转为页面引用」的口径

| 选区情形 | 表现 |
|---|---|
| 跨块 | **不渲染**（没有单一标题语义；置灰会误导用户去改文本再试） |
| 覆盖已渲染单元（chip / 标签 / 日期） | 置灰 + 点名选中了什么 |
| 标题含 `[` / `]` | 置灰 + 点名方括号 |

编辑态（单块 TipTap 内）只认**语法前缀**：外链 chip 的语法字符在文档里是真实文本（0067 D8 只做零宽隐藏），`textBetween` 会带出完整 `[标题](url)`，命中就直说「选区包含已有链接」，不让用户去找屏幕上看不见的方括号。渲染态那一侧由 `firstNonPlainUnitInRange` 拦，两处同构。

### D5 写回：保留选区的行内格式，光标落 `)` 之后

- 渲染态：`planTextRangeLinkWrap`（`services/text-range.ts`）。与 `planTextRangeReplacement` 的唯一差别是**不丢弃**被替换区间的 marks，而是把它们平移到标题位（`lo + 1`）。复用替换计划会让「选中加粗文字加链接」静默掉格式。
- 编辑态：一次 `insertContentAt` 插三段（`[` / 带原 marks 的标题 / `](url)`），语法字符不带格式，与上面同一口径。
- 写完关浮层、光标落字面末尾（`chip.to`），接着就能写正文；**不补前后空格** —— 外链是行内文本，不是键盘原子单元。
- 渲染态写回后必须 `flushSave`：`renderSegments` 已过时被清空，不落库会停在裸字面态。

落点与焦点有三条不显然的约束，改动这块前须知道：

1. `planTextRangeLinkWrap` 返回的 `caretOffset` 是**内容偏移**，`activateBlock` 收的是 **ProseMirror 文档位置**（首位之前 = 1），调用处必须 `+1`。少这一步光标停在隐藏尾巴 `(` 之前，看着在 chip 末尾，接着打字却写进隐藏语法。
2. 激活前要丢掉 `pendingClickCoords`。`focusActiveEditor` 的优先级是「点击坐标 > cursorPos」，而渲染态拖选文字必然在选区起点留下一次点击坐标 —— 不清就顶掉本轮的 `cursorPos`，光标落回鼠标按下处，且 `pendingCursorPos` 一直挂着不被消费。
3. 面板挂载即聚焦 URL 输入框，编辑器 `isFocused` 随即变 false。`updatePosition` 必须把「焦点落在 `.floating-submenu` 内」当作工具条仍可用；否则 blur 触发的重新定位会 `hide()` 并清掉二级状态，编辑态点按钮只闪一下（渲染态不受影响，那边判据不看焦点）。

### D6 不抓网页元数据

用户给的标题就是真标题。ADR-0067 的抓取规则明确「用户手动改过的别名永不覆盖」，这里同理：写完不抓，切卡片/预览视图时按卡片挂载的 `needsFetch` 自行抓。代价是卡片视图刚打开时可能只有标题没有封面，与手打 markdown 链接完全一致。

### D7 `Ctrl+K` 归「添加链接」，搜索面板搬到 `Ctrl+P`

- 有可用选区（单块、标题合法）：打开链接面板，`preventDefault` + `stopPropagation`；
- 没有可用选区：**静默无反应**。全局不再有第二个 `Ctrl+K` 消费者；
- 两条路径不会同时开花：编辑态的 wrapper 监听先 `stopPropagation`，BlockList 的 document 监听收不到；
- 搜索面板改 `Ctrl+P`，**必须 `preventDefault`** —— WebView2 里它的默认行为是打印。

`Ctrl+K` 在代码里从未有过 UI 提示（只有一处注释），改绑定的可见成本为零。

## 已否决的替代方案

- **合并成「链接」下拉（主按钮 + 外链/内链二选一）**：浮层宽度不增长，但外链多一次点击，且要拆掉 Brackets 的直达行为——为省 36px 牺牲一个已有的一步操作。
- **单输入框只填 URL，标题固定为选区文字**：更简，但想改显示文字得回头再走 chip 悬浮条，等于把一次编辑拆成两步。
- **允许任意 scheme**：写进去点不开，等同于制造死链。
- **标题含方括号时自动剔除后写入**：静默改字，用户不知道少了个字。
- **做完抓一次元数据**：违反「用户标题优先」的既有规则，且给每次加链接增加一次网络请求与失败分支。
- **绑 `Ctrl+Shift+K`**：避开冲突但也避开肌肉记忆，同时要在编辑态与渲染态各接一套键位。
- **表格选区浮层同时长出这个按钮**：写回路径与判据都要单独补，在没有写入的情况下按钮是死的。

## 后果

- 选区浮层出现第四个二级浮层（对齐 / 取色 / 链接），三者互斥由 `SubmenuKind` 的单状态保证。
- 公共段的「同序同形」约定出现一个显式例外，表格接入后必须撤掉，否则会长期留在代码里。
- `Ctrl+P` 依赖 `preventDefault` 压住 WebView2 的打印默认行为；非 Tauri（浏览器）环境下 Ctrl+P 同样是打印，测试需覆盖。
- 测试面：`utils/inline-link.test.ts`（判据与抽取）、`text-range-replace.test.ts`（包裹规划器，含格式保留）、`InlineFormatToolbar.test.ts`（三态 + 面板闭环）。
