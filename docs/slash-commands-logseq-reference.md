## Phase 1.1 MVP 命令清单（18 个）

### 分组 1：日期时间（Date & Time）

| 命令 | 别名 | 插入内容 | 说明 |
|------|------|----------|------|
| `/Today` | `/今天` | `[[2026-04-23]]` | 今日日期链接（Logseq 核心命令） |
| `/Tomorrow` | `/明天` | `[[2026-04-24]]` | 明日日期链接 |
| `/Yesterday` | `/昨天` | `[[2026-04-22]]` | 昨日日期链接 |
| `/Time` | `/时间` | `00:32` | 当前时间 |
| `/Date picker` | `/日期选择` | `[[YYYY-MM-DD]]` | 弹出日期选择器 → 选择后插入日期链接 |

**Logseq 行为参考**：
- `/Today` 会跳转到当天的 Journal 页面（如果有）或创建新页面
- 日期链接使用 `[[YYYY-MM-DD]]` 格式，双链可点击跳转

### 分组 2：任务状态（Task Status）

| 命令 | 别名 | 行为 | 说明 |
|------|------|------|------|
| `/TODO` | `/待办` | 在 Block 开头插入 `TODO ` | 待办事项 |
| `/DOING` | `/进行中` | 在 Block 开头插入 `DOING ` | 正在进行 |
| `/DONE` | `/完成` | 在 Block 开头插入 `DONE ` | 已完成 |
| `/LATER` | `/稍后` | 在 Block 开头插入 `LATER ` | 稍后处理 |
| `/NOW` | `/现在` | 在 Block 开头插入 `NOW ` | 当前焦点 |

**Logseq 行为参考**：
- 任务状态通常放在 Block 开头
- 支持循环切换（`Ctrl+Enter` 切换 TODO → DOING → DONE）
- Phase 1.1 先实现标记插入，Phase 2 实现状态切换逻辑

### 分组 3：文本格式（Text Format）

| 命令 | 别名 | 行为 | 说明 |
|------|------|------|------|
| `/Bold` | `/粗体` | 选中时包裹 `**文字**`；未选中插入 `****|****` | 粗体 |
| `/Italic` | `/斜体` | 选中时包裹 `*文字*`；未选中插入 `**|**` | 斜体 |
| `/Highlight` | `/高亮` | 选中时包裹 `^^文字^^`；未选中插入 `^^^|^^` | 高亮（Logseq 用 `^^`） |
| `/Code` | `/代码` | 选中时包裹 `` `文字` ``；未选中插入 `` `|` `` | 行内代码 |
| `/Code block` | `/代码块` | 创建新 Block，内容为空代码块 | 块级代码 |

**Logseq 行为参考**：
- 选中文字后执行命令会包裹选中内容
- 未选中时插入模板（如 `**|**` 光标在中间）

### 分组 4：链接引用（Link & Reference）

| 命令 | 别名 | 行为 | 说明 |
|------|------|------|------|
| `/Page reference` | `/页面引用` | 插入 `[[|]]` | 内部页面链接 |
| `/Tag` | `/标签` | 插入 `#` | 标签 |

**Logseq 行为参考**：
- `/Page reference` 会弹出页面搜索面板

### 分组 5：页面操作（Page Actions）

| 命令 | 别名 | 行为 | 说明 |
|------|------|------|------|
| `/Search or create page` | `/搜索页面` | 弹出页面搜索面板 | 搜索/创建 |
| `/New page` | `/新建页面` | 创建并跳转新页面 | 新建 |

**Logseq 行为参考**：
- `/Search or create page` 是最常用的页面导航命令
- 输入不存在页面名会提示创建

## 与 Logseq 的差异

| 特性 | Logseq | comind |
|------|--------|--------|
| 高亮语法 | `^^text^^` | `^^text^^`（保持一致） |
| 任务状态 | `TODO` `DOING` `DONE` `LATER` `NOW` `WAITING` `CANCELLED` | 同左（Phase 1.1 实现前 5 个） |
| 日期链接 | `[[YYYY-MM-DD]]` | 同左 |
| 页面搜索 | `/Search or create page` | 同左 |
