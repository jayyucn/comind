## 1. 产品定位

**comind 不是一个笔记工具，而是一个认知增强系统。**

| <br /> | 笔记工具（Logseq/Obsidian） | comind      |
| ------ | --------------------- | ----------- |
| 核心隐喻   | 知识图谱                  | 自我对话        |
| 价值主张   | 收集、连接、检索信息            | 记录、反思、调整行为  |
| 核心用户动作 | 写文档、建链接               | 快速捕捉状态、看见模式 |
| 数据角色   | 静态知识库                 | 动态认知伙伴      |

**一句话定义：**

> comind 是一个高度可自定义的认知与能力增强辅助工具，帮助使用者通过记录、反思和间隔重复，提升自我认知和行为质量。

## 2. 核心用户需求

### 2.1 四大核心维度

| 维度      | 核心问题       | 实现方式                                |
| ------- | ---------- | ----------------------------------- |
| ⏰ 时间管理  | 时间花在哪了？    | 简单活跃度统计（Block 创建/编辑数）               |
| 💭 情绪管理 | 什么在影响我的状态？ | **独立界面**（四象限快速选择 + 趋势图 + 每周复盘细粒度回顾） |
| 🧠 深度思考 | 我的思维盲区在哪？  | 思维模型库 + Block 编辑器                   |
| 📚 知识管理 | 重要知识如何保留？  | Block + WikiLink + 间隔重复 + App 内弹窗提醒 |

### 2.2 每周复盘（精力/注意力/目标/决策的统一入口）

精力、注意力、目标对齐、决策质量**不要求逐日手动标签**（手动标签摩擦高、依从性低，容易变成摆设）。

改为通过**每周复盘**统一处理：

**设计理念：**

- 不要求每天打标签（高摩擦 → 低依从性 → 数据空洞 → 功能摆设）
- 改为每周一次结构化复盘（低频率 → 高依从性 → 高质量数据）
- 复盘时思考更深入，答案比逐日标签更有价值

**情绪记录（逐日，粗粒度）：**

- 在 `/mood` 界面提供四象限快速选择（Canvas 实现，方案 A）
- 点击任意情绪词 → 1 秒完成，写入 `#情绪:焦虑`
- 低摩擦，不影响写作流

**每周复盘（细粒度）：**

- 问题 1「这周精力最好的时候是？什么时候最差？」引导详细回顾
- 可链接到本周具体 Block

**两者分工明确：**

| 功能         | 粒度     | 频率     | 目的                  |
| ---------- | ------ | ------ | ------------------- |
| 情绪管理（四象限）  | 逐日，粗粒度 | 每天（可选） | 实时感知「我现在什么感觉？」      |
| 每周复盘（问题 1） | 每周，细粒度 | 每周一次   | 回顾总结「这周整体精力/情绪怎么样？」 |

**每周复盘引导问题：**

| # | 问题                 | 覆盖维度    |
| - | ------------------ | ------- |
| 1 | 这周精力最好的时候是？什么时候最差？ | 🔋 精力   |
| 2 | 这周什么消耗了最多注意力？      | 🎯 注意力  |
| 3 | 这周最深的思考是什么？        | 🧠 深度思考 |
| 4 | 这周有哪些决策需要复盘？       | 📐 决策质量 |
| 5 | 下周最重要的 3 件事？       | 🎯 目标对齐 |

**数据存储：**

- 复盘回答写入 Weekly Review Page（`/page/weekly-{date}`）
- 可链接到具体 Block（双向关联）
- 时间线视图按周聚合显示复盘结果

**Block 2（AI 增强）补充：**

- 开启 AI 后，系统自动分析每日文字，检测情绪/精力/注意力
- 自动打标签（可手动调整）→ 逐日数据也有了，且零摩擦
- 每周复盘时可参考 AI 自动生成的周报

### 2.3 两个核心能力

1. **辅助思考** — 帮助把模糊想法变清晰，把隐性知识显性化
2. **记忆曲线推送** — 基于间隔重复算法，App 内弹窗提醒，确保重要知识不遗忘

## 3. 产品原则

### 3.1 AI 是可选的

- 核心功能不依赖任何外部 API
- AI 功能通过 Settings 开关控制，关闭后软件完全可用
- 用户可自带 API Key（OpenAI/Anthropic）或运行本地 Ollama
- AI 功能通过独立数据表实现，核心 DB 不感知其存在

### 3.2 为自己用，不为所有人用

- 数据格式按实际需要调整，不做通用迁移兼容
- 功能按真实痛点做，不做"别人可能用得上"的功能
- UI 按个人审美设计，不追求通用适配
- 可以激进（如直接接入本地 LLM，隐私 100% 可控）

### 3.3 大纲是手段，不是目的

- Block 编辑器是输入手段之一，不是产品的核心价值
- 核心价值在于：数据 + 分析 + 主动干预

### 3.4 知识不仅要记住，还要用上

- 间隔重复不只是"背出来"，而是"重新进入上下文"
- 复习时带回原始思维链，而非孤立卡片
- 主动式知识召回（上下文触发）比被动推送更有价值

### 3.5 遗忘是有价值的

- 过时的知识该被清理，不是永远保留
- 沉寂检测机制：6 个月无引用的 Block 降低权重
- 定期提示用户确认是否保留

### 3.6 不做独立模块

- 精力/注意力管理不作为独立模块开发
- 所有维度共用同一套基础设施（Block + Property + 时间线）
- 区别只在于记录什么、分析什么

### 3.7 系统内容复用现有界面

- 思维模型详情等系统内容，**复用 Page 界面**
- 通过内置属性（如 `_system: true`）控制为只读模式
- 不开发独立的"详情页"，保持界面一致性

### 6.1 思维模型库设计

**数据来源：** 静态 JSON（15-20 个模型，4 个分类）

**分类（查理·芒格式）：**

| 类别       | 示例模型                |
| -------- | ------------------- |
| 🎯 决策类   | 二阶思维、逆向思维、机会成本、沉没成本 |
| 💡 创新类   | 第一性原理、横向思维、SCAMPER  |
| 🔍 批判性思维 | 贝叶斯更新、奥卡姆剃刀、汉隆剃刀    |
| 🔧 问题解决  | 5WHY、鱼骨图、MECE、金字塔原理 |

**模型详情页设计：**

- **复用 Page 界面**（`/page/:id`）
- `Page.type` 扩展为包含 `'system'`（标记为系统页面，只读）

- Block 内容包含：模型解释 + 使用示例 + 适用场景

**模板生成：**

- 点击"使用此模型" → 生成结构化 Block（预填充模板）
- 模板格式：
  ```
  # 二阶思维

  ## 我的初始想法
  {{user_input}}

  ## 二阶问题
  - 这个想法的结果会是什么？
  - 如果每个人都这么做会怎样？
  ```

### 6.3 情绪四象限设计（Canvas，方案 A）

**模型：** 效价（Valence）× 唤醒度（Arousal）连续体，情绪词按心理学坐标精确定位。

**Canvas 实现（方案 A）：**

```vue
<!-- src/components/EmotionQuadrant.vue -->
<template>
  <canvas ref="canvas" width="400" height="400" />
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue'

const canvas = ref<HTMLCanvasElement>()

// 情绪坐标数据（效价 × 唤醒度，归一化到 [-1, 1]）
const emotions = [
  // 正向·高唤醒（右上象限）
  { name: '兴奋', valence: 0.8, arousal: 0.9 },
  { name: '期待', valence: 0.7, arousal: 0.7 },
  { name: '愉快', valence: 0.9, arousal: 0.6 },
  // 正向·低唤醒（右下象限）
  { name: '平静', valence: 0.7, arousal: -0.3 },
  { name: '放松', valence: 0.6, arousal: -0.5 },
  { name: '满足', valence: 0.8, arousal: -0.2 },
  // 负向·高唤醒（左上象限）
  { name: '焦虑', valence: -0.6, arousal: 0.8 },
  { name: '愤怒', valence: -0.8, arousal: 0.9 },
  { name: '压力', valence: -0.5, arousal: 0.7 },
  // 负向·低唤醒（左下象限）
  { name: '沮丧', valence: -0.7, arousal: -0.6 },
  { name: '疲惫', valence: -0.5, arousal: -0.8 },
  { name: '失望', valence: -0.6, arousal: -0.4 },
]

onMounted(() => {
  const ctx = canvas.value?.getContext('2d')
  if (!ctx) return
  
  // 绘制四象限背景
  drawQuadrants(ctx)
  // 绘制坐标轴
  drawAxes(ctx)
  // 绘制情绪词（按坐标定位）
  drawEmotions(ctx, emotions)
  
  // 点击事件：检测点击了哪个情绪词
  canvas.value?.addEventListener('click', (e) => {
    const emotion = hitTest(e, emotions, canvas.value!)
    if (emotion) {
      // 写入 Property #情绪:焦虑
      store.dispatch('setProperty', { key: '情绪', value: emotion.name })
    }
  })
})
</script>
```

**交互：**

- 点击任意情绪词 → 1 秒完成，写入 `#情绪:焦虑`
- 同一象限内的情绪词根据效价 × 唤醒度区分相对位置
- Canvas 绘制，支持精确坐标定位

**工作量：** L（Canvas 绘图 + 点击检测 + 响应式适配）

### 6.6 间隔重复弹窗提醒设计

**交互流程：**

```
┌─────────────────────────────────┐
│  🔔 复习提醒                      │
├─────────────────────────────────┤
│  有 3 个 flashcard 待复习          │
│                                 │
│  [开始复习]  [稍后提醒(1小时)]    │
└─────────────────────────────────┘
```

**实现：**

- 在 App 根组件（App.vue）中设置定时器
- 每分钟检查 `reviews` 表，找出 `nextReview <= now` 的记录
- 有记录 → 显示弹窗
- 点击"开始复习" → 跳转到 `/review`

**注意：** 此功能在 Block 1 中实现（不依赖 AI），使用定时器即可，无需系统级通知权限。

## 8. 不做的事（Scope Boundary）

以下功能 **不在当前规划内**，后续视需求决定是否加入：

| 功能              | 原因                   |
| --------------- | -------------------- |
| 多用户 / 协作编辑      | 给自己用，不需要             |
| 云端同步（第一阶段）      | 本地优先，后续再考虑           |
| 复杂的导入/导出        | 自己用，需要时再写            |
| Onboarding 流程   | 自己就是用户               |
| 移动端 App         | 聚焦桌面端，后续再考虑          |
| 富媒体标注（PDF/网页高亮） | 通过浏览器扩展解决            |
| 社交功能 / 分享       | 不涉及                  |
| 插件系统            | 给自己用，直接改代码更快         |
| 思维模型教学（教育功能）    | 不属于核心功能，可后续加入        |
| 独立统计画像界面        | 降级：嵌入已有界面（时间线/复习/复盘） |
| 时间线多维度曲线        | 降级：简单活跃度统计           |

## 9. 成功标准（Block 1 完成）
