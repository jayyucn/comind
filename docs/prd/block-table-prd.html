1背景与目标

当前页面由 Block 树构成，可用的内容类型是 bullet、code、image、embed 等。用户需要在笔记里记录 “并列对照、分工清单、参数比较”这类二维信息时，只能把内容摊成多级 bullet，或者塞进代码块。

观察到的现象

  • 用多级 bullet 表达二维关系时，行与列靠缩进和空格对齐，换行、增删一项就会整体错位。
  • 塞进代码块可以对齐，但会丢失文字样式、无法逐格编辑，也不适合日常记录。
  • 为了对齐，用户会在单元格之间手工敲空格或制表符，之后维护成本高于重新录入。

受影响的用户与时机　在 Page 中连续书写、需要把多条信息并排比较的记录者（会议纪要、方案对比、读书摘录、任务分工）。

产品决策　引入一种新的 Block 类型：表格块。它仍是 Block 树中的一个节点，但在内容区渲染为可编辑的二维网格；单元格只承载纯文本。

期望的可观察结果　用户能在当前页面完成“建表 → 填表 → 增删行列”，离开页面后再次打开，表格的尺寸与内容与离开时一致；整张表可以像普通块一样被选中、复制、删除与撤销。

P1 — 明确支持但不进入本轮验收

  • 从 Excel / 其他表格应用粘贴 TSV，直接生成表格块。
  • 列宽拖动调整，并按表格块持久化。
  • 单元格内换行（Shift+Enter / 多行文本）。
  • 拖拽调整行、列顺序。

非目标 — 本 PRD 明确不做

  • 合并单元格、公式、排序、筛选、统计与条件格式。
  • 单元格内嵌 Block、图片、附件或链接卡片（单元格只有纯文本）。
  • 把表格块当作任务或字段的数据源；这属于查询视图（TableView）的职责。
  • 多表联动、跨页引用整张表、把表作为独立页面实体。
  • 移动端专属的手势交互（随端能力另行定义）。

3产品模型

3.1 表格块

属性定义
对象身份Block 的一种 type，与 bullet / code / image / embed 同级；沿用 Block 的 id、父级与排序位置，可缩进、可排序、可整块移动。
节点形态叶子块：不拥有子 Block。表格结构不由子 Block 表达，而是由表格自身持有。
内容一个 行 × 列 的网格；每个单元格是一段纯文本；首行可标记为表头。
折叠没有子块、也没有字段行时，不满足现有折叠条件，因此不显示折叠入口。表格自身不引入新的折叠状态。
字段区沿用 Block 既有规则；表格块不额外增加“表格专属字段”。

3.2 交互状态

表格块在编辑上下文中只有两种状态，任何时刻只处于其中一种。这个模型决定了键盘行为由谁接管。

状态图：块级未聚焦 ⇄ 单元格编辑

状态约束

  • 编辑是唯一会消费文字输入的状态；此时 Enter / Tab / 方向键属于表格，不得冒泡给页面块编辑器（否则会拆分或新建 Block）。
  • 进入编辑后，Esc 或点击表格外都会结束编辑并保留已输入内容，回到块级未聚焦；块级未聚焦时，表格块与普通块一样参与块选择、复制、删除与拖拽排序。
  • 只读上下文（历史页快照）不进入编辑状态：单击只选中单元格，可选中、可复制，不可输入；也不显示操作条与表头开关。

3.3 创建流程

创建流程：就地转换或新建，最终聚焦首行首格进入编辑

4功能需求

每条需求按“触发 → 处理 → 结果与状态变化”描述，界面行为以可交互原型为准。

操作入口　表格块不常驻工具栏。入口依附在表格外缘，按三级显隐：

① 默认（鼠标不在块内）：不显示任何控件。

② 块 hover：表格顶边外侧出现贯穿全宽的列操作条基座，左缘外侧出现行操作条基座，左上角出现表格菜单按钮。基座只作定位提示，不响应点击。

③ 压在某段条上：该段升亮，「条」可整段点击弹出该行 / 列菜单（删除、清空、复制、剪切、粘贴、移动）。

④ 压在该段条的端点（即「+」自身所在的一小块区域内）：才浮出「+」与引导线。「+」为一步插入（行下方 / 列右侧）。三级与四级分开，是因为条是整段长条——若「+」跟着整段走，光标压在条的任意位置都会把几十像素外的「+」拉出来，插入入口的触发区就被放大到整条。行列两个方向完全对称。

点击入口不改变当前单元格焦点，操作完成后焦点回到原格。表头行不提供「+」插入行，列菜单仍可用。只读上下文不显示任何入口。

菜单打开期间　同类操作条整排保持可见并维持基座色，被点开菜单的那一段继续深一档：菜单浮在表格之外，鼠标移入菜单后块 hover 已经断开，若仍只按 hover 显隐，整条带子会连同「菜单属于哪一列 / 哪一行」一起消失。此时另一方向的条（列菜单对应行条、行菜单对应列条）保持隐藏，避免两侧同时亮起造成方向歧义。菜单关闭后整排立即回到默认隐藏。

超宽表格　列数超出显示宽度时，表格横向滚动，操作条只画在可视宽度内：随内容一起左右滚动、与列边界保持对齐，但不得溢出到表格右侧的空白区域。被右边界裁切的那一列，其「+」位于可视区之外，不显示；滚动到该列完整可见后再出现。行方向的横向引导线同样止于可视右边界。表格底边下方另有横向滚动条：滑块长度按可视宽度与内容宽度之比计算，贴在表格下方留白内、与表格左边对齐，可拖拽滚动；列宽总和回落到可视宽度以内时随之消失。全局浮层滚动条只服务纵向，横向溢出若无此控件将没有任何可发现的滚动提示。

TBL-01创建表格块

触发
光标位于某个 Block 内，输入 /table 并在斜杠菜单中确认（回车或点击菜单项）。
处理
仅当当前块内容为空（只有斜杠命令文本）且没有子块时，就地清除命令文本并把该块转换为表格块；转换不改变块上已有的字段值，字段区按既有规则显示在表格下方。
若当前块已有其他文本，或带有子块，则清除命令文本、保留其余内容与子块，并在该块完整子树之后插入一个新的表格块，原有子块不会被表格吞并。页面内与 BlockModal 的插入位置遵循同一父子约束：新表格块作为当前块的兄弟插入；在 BlockModal 中若当前块是子树根，则新表格块作为根块的子块插入，不在根层新增兄弟节点。
结果
页面内出现一张默认尺寸的表格，焦点落在表格首格并进入编辑状态；/ 命令文本不再残留。
状态
块类型变为 table；表格进入“单元格编辑”态；该操作记入页面撤销历史的一条记录。

例外：在只读上下文、或当前块被其他浮层占用时，创建入口不可用。

TBL-02默认结构

触发
表格块首次创建。
处理
生成 3 行 × 3 列的空网格，首行默认标记为表头；列宽在内容区内均分，并保持最小可读列宽。单元格不写入任何默认文本：表头格为空时显示占位提示，数据格为空时不显示占位字符。
结果
表头行以浅色底、加粗文字与普通行区分；网格以细线分隔，整体宽度占满块内容区；单行文本按列宽换行显示，行高随内容增长；内容区不足以容纳最小列宽时，表格在内容区内横向滚动，不压缩列宽。
状态
表格具备“行数、列数、首行是否为表头”三个可持久化属性。
Assumption 默认 3 × 3 与“首行默认表头”是基于现有记录习惯的假设；若评审认为应默认 2 × 2 或无表头，只改默认值，不改变其余规则。[Assumption, TBD]

文字规则：单元格只接受单行纯文本，输入与粘贴都不产生换行；显示时按列宽自动换行，内容不截断。空数据格不显示占位字符（表头格的占位见 TBL-02）。表格文本不参与标签解析、日期引用与链接识别，也不进入页面搜索与引用匹配（后续是否支持见 Q2）。

TBL-04行操作

触发
在目标行的行操作条上点「+」（在该行下方插入一行），或点击行操作条后在菜单中执行“删除行”。
处理
插入由「+」一步完成；删除、清空、复制、剪切、粘贴、上移、下移在行菜单中提供，菜单不重复插入项。粘贴用剪贴板中的行整行覆盖当前行：列数不变，剪贴板比当前表窄时其余格清空，不新增行。
结果
插入行落在指定位置，行数 +1；删除行后其下各行上移，行数 −1；当前焦点保持在原列，位置按新结构修正；操作条随新焦点所在行更新。
状态
行数变化；结构操作单独记入撤销历史。

边界：表格至少保留一行。对唯一一行执行删除时，改为清空该行内容并给出提示，不产生 0 行的表格。表头标记固定绑定在首行：删除原表头行后，新首行自动继承表头样式；若希望无表头，需通过“首行表头”开关关闭。

TBL-05列操作

触发
在目标列的列操作条上点「+」（在该列右侧插入一列），或点击列操作条后在菜单中执行“删除列”。
处理
插入由「+」一步完成；删除、清空、复制、剪切、粘贴、左移、右移在列菜单中提供，菜单不重复插入项。粘贴用剪贴板中的列整列覆盖当前列：行数不变，剪贴板比当前表短时其余行清空，不新增列。
结果
插入列落在指定位置，列数 +1；删除列后其右各列左移，列数 −1；新增列宽与其他列一致；操作条随新焦点所在列更新。
状态
列数变化；结构操作单独记入撤销历史。

边界：表格至少保留一列。对唯一一列执行删除时，改为清空该列内容并给出提示。删除列时，该列所有单元格文本一并移除；撤销可整体恢复。

TBL-06首行表头

触发
操作条中的“首行表头”开关。
处理
开启时首行使用表头样式并参与“首行”语义；关闭时首行恢复为普通数据行，内容不变。
结果
样式立即切换；表头单元格仍可编辑；表格尺寸与内容不变。
状态
表头标记变化并持久化；记入撤销历史。

表头只影响首行的视觉与语义，不影响列宽、行顺序或导出结构。不存在“多行表头”或“首列表头”的形态。

原型 可交互表格块 · 对应 TBL-01 ～ TBL-06
—
单击格即编辑 · Enter 下一行同列（末行新增）· Tab 右一格（末格新增）· Esc 结束编辑 · 上下方向键换行。原型以常驻操作条展示，最终形态见第 4 节“操作入口”（三级 hover 显隐，插入走「+」）。

TBL-07整块操作：选中、复制、删除

触发
Ctrl/Cmd + 单击表格块所在行（单元格以外的块行区域），或使用块级多选；也可通过块菜单执行删除。
处理
表格块作为一个整体参与块选择。复制时整张表进入内部剪贴板；剪切、删除与普通块一致。粘贴时生成新的表格块，保留行数、列数、表头标记与全部单元格文本；不保留旧 id 与位置。
结果
粘贴后的表格与原表内容一致、位置独立；删除整块后页面不再显示该表。
状态
块选择状态；删除与粘贴各记入撤销历史。

纯文本回退：复制到外部应用时，以制表符分隔单元格、换行分隔行；单元格内的制表符与换行替换为空格，避免破坏行列结构。外部纯文本粘回 comind 时按现有规则作为文本处理，不自动成表（见 P1）。

TBL-08撤销与重做

触发
Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y。
处理
沿用页面级唯一撤销栈：单元格内的撤销/重做快捷键交由页面栈处理，不启用输入控件的原生文本撤销；连续输入以 500ms 停顿或焦点变化为界合并为一条，跨单元格不合并；插入/删除行列、切换表头、创建或删除整块各为一条。表格不建立第二套历史。
结果
撤销后网格尺寸、表头状态与单元格文本整体回到该条记录之前；重做恢复。
状态
表格结构与内容同时回滚；焦点可落在最近一次操作的单元格。

TBL-09持久化、快照与同步

触发
任何单元格输入或结构变更；页面关闭/重开；历史点滴页物化；跨端同步。
处理
表格的网格数据随所属 Block 一并保存。历史页快照生成时，表格数据作为页面内容的一部分被完整复制；快照中的表格只读。
结果
重新打开页面（含重启应用）后内容与尺寸一致；历史页显示当日快照中的表格；另一端收到同步后显示相同内容。
状态
表格数据属于 Block 内容，不属于视图偏好；不新增独立的同步实体。

说明：不承诺“单元格级冲突合并”。并发写入遵循现有 Block 级同步策略，冲突结果以到达顺序与既有规则为准 [TBD]。

TBL-10打开方式与可编辑性

触发
页面内直接渲染；或作为某个被打开块的后代出现在 BlockModal 中。
处理
两种上下文使用同一表格渲染与交互；可编辑性由上下文决定，而不是页面日期。表格块是叶子块，自身不能作为 BlockModal 的根被打开。
结果
活上下文（页面内、任务卡片、BlockModal 中的可编辑子树）中表格完全可编辑；快照上下文中只读，不显示操作条与表头开关。点击表格块的 bullet 圆点不打开 BlockModal，而是把焦点落到表格首格。
状态
表格块不提供子树展开入口；圆点行为与“无子树”一致。

TBL-11导出与模板序列化

触发
页面导出为 Markdown；把含表格块的内容保存为模板。
处理
Markdown 导出按 GFM 表格语法输出：单元格内的竖线转义为 \|，制表符与换行替换为空格；首行为表头时直接输出表头与分隔行；首行未标记为表头时，补一个空表头行与分隔行，再输出全部数据行，保证语法合法且不丢内容。模板序列化中跳过表格块，不参与“不支持类型降级为 bullet”的路径。
结果
导出文件可被通用 Markdown 工具还原为表格，表头关闭的表也能完整保留数据行；保存模板时明确提示“模板不包含表格内容”，应用模板不会产生空块。
状态
导出不修改源数据；模板保存不改变页面中的表格。

TBL-12单元格文本选择与复制

触发
在单元格内按下左键并拖动，光标始终不离开起点格；或在格内双击选词。只读上下文同样可用。
处理
选择范围严格限定在起点格内：编辑态由单元格自身的文本控件完成选择，渲染态由格内文本的原生选区完成；离开起点格后立即转为区域选择（TBL-13），此前的跨格文字选区不再保留。
结果
只有该格内的文字呈选中态，相邻单元格不会被选中；复制得到这段纯文本。
状态
不产生页面的文本选区或块选区，不改变表格焦点所在格，不产生撤销记录。

说明：选择只在「起点格」内成立。光标一旦出格，语义从「选文字」切换为「选格子」，两段之间不存在同时成立的状态——这正是「光标只经过 A 格，B 格却被选中」的根因所在：把整张表当成一条按行优先拼接的字符流后，从 A 格往下拖一点，字符偏移就已经越过了整行后面的 B 格。

TBL-13整格区域选择

触发
左键按下于某格内，拖动时光标离开起点格；或在格内按下后拖出表格边界。
处理
以起点格与当前格张成的矩形为选区，行列都含端点；反向拖动先归一为左上 → 右下再渲染。光标离开表格边界时，端点钳制到最近的格。区域内每一格各自铺一层底色，格线保持可见；区域外的格不参与。期间不产生任何跨格文字选区。
结果
区域内各格呈选中底色。区域选择存在时：Ctrl+C 按制表符分隔列、换行分隔行输出，可直接粘进表格软件；Delete / Backspace / Ctrl+X 只清空区域内各格的文字，行列数与表头设置不变，全空时不产生保存。单击格内或表格外任意位置撤销区域选择。
状态
不改变焦点所在格；清空内容按一次输入突发记入撤销历史；区域选择本身不是文档状态，切页、失焦后不再保留。

起点在表格外　按下位置不在任何格内、拖动过程中经过或停在表格上时，表格按原子单元整体入选：一条覆盖整表的色带，不进入格级区域选择。表格的文本是各格拼接的产物、块 content 为空，字符级切片既复制不出内容也回写不了，因此不参与跨块的逐字选择。整表复制走块级载荷（TBL-07），纯文本回退为整表 TSV。

Assumption 区域选择不提供「拖拽填充」「整行整列选择」等电子表格的进阶语义，也不在格内选区上叠加编辑态文字操作（渲染态下格内文字选区上的删除键保持浏览器原生行为：不修改内容）。[Assumption, TBD]

5共享规则与例外

5.1 键盘归属

表格进入“单元格编辑”态时，Enter、Tab、Esc 与方向键由表格接管，必须阻止其冒泡到页面块编辑器。否则按 Enter 会拆分 Block、按 Tab 会触发块缩进。输入法组合期间，所有导航键交还输入法。这条规则同时约束页面内和 BlockModal 两个上下文。

5.2 空值与占位

  • 空单元格是合法状态，保存为空字符串，不视为错误。
  • 占位提示仅用于引导，永远不会被当作内容保存。
  • 粘贴、复制与导出时空单元格保留位置，不压缩行列。

5.3 结构底线

表格始终至少保留 1 行 1 列。所有删除入口在触线时转为“清空”并提示，不产生空表。表格不存在“0 行”或“0 列”的持久化状态。

5.4 规模限制

TBD 单表行数、列数与单元格字符长度的上限尚未确定。达到上限时，对应的“插入行/列”入口应禁用并给出提示。评审需给出具体数值；在此之前不承诺任何固定上限。[TBD]

5.5 与现有机制的关系

现有机制对表格块的要求
Block 类型注册与渲染新增 table 类型，与既有类型同级；页面内与 BlockModal 共用同一渲染与交互实现，不出现两套表格。
折叠（Collapse）表格为叶子块；无子块且无字段行时不满足折叠条件，不显示折叠入口；不修改现有“折叠由单一状态驱动”的不变式。若表格块保留了字段值，字段区按既有规则正常显示。
撤销历史只使用页面级唯一撤销栈；单元格内的撤销快捷键同样路由到页面栈，不启用原生文本撤销；输入突发与结构操作按第 4 节粒度记录。
块级剪贴板表格整块进入块剪贴板载荷；粘贴为新表格块，尺寸、表头与文本完整保留。
页面快照表格数据随 Block 进入快照；历史页只读展示，编辑不触碰快照。
同步作为普通 Block 随页面同步，不新增同步表或独立实体。
模板序列化跳过表格块，不按“不支持类型降级为 bullet”处理；保存模板时提示不包含表格内容，避免空 bullet 造成静默丢失。
块字段区沿用既有字段区规则，不新增表格专属字段；表格本身不是字段数据源。

5.6 权限与只读

表格块沿用页面级权限：能编辑页面即可编辑表格；只读页面不提供单元格输入与行列操作。历史点滴页的快照上下文只读，但表格中的文本可以选中并复制。删除整块属于可撤销操作，不引入额外确认弹窗。
