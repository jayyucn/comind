## T9 · 阅读态点击编辑闭环 — 完成 ✅

### 数据流
```
阅读态点击 .date-ref span
  → BulletRender.vue @click → emit('content-click', MouseEvent)
  → Block/index.vue handleContentClick(e):
      1. target.closest('.date-ref') → 读取 data-* 属性
      2. 查找该 span 在 block.content 中的位置（支持重复内容）
      3. openDateRefPanel(payload, 'content')
      4. DateTimePickerPanel 显示（预填旧值）
  → 用户修改 → "确定"
  → handleConfirm(value):
      if (source === 'content'):
        block.content = (0..from) + newText + (to..end)
        blockStore.updateBlockContent(blockId, newContent)
  → closeDateRefEditor()
```

### 重复内容处理

同一个 block 中有多个相同 `{{...}}` 时，通过 `occurrence` 索引精准定位：
```ts
const allDateRefs = blockText.querySelectorAll('.date-ref')
// 数该 span 是第几个
for (let i = 0; i < allDateRefs.length; i++) {
  if (allDateRefs[i] === dateRefSpan) { occurrence = i; break }
}
// 在 content 中找第 N 个匹配的 dateRef
while ((m = searchPattern.exec(content)) !== null) {
  if (m[0] === raw && matchCount++ === occurrence) { idx = m.index; break }
}
```
