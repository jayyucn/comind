### 废弃命令

### `/schedule` `/deadline` 行为

```
/schedule → 打开 DateTimePickerPanel（kind=schedule）
  → 用户选择日期/时间/重复规则
  → 确认 → 插入 {{schedule:iso|recurrence}}

/deadline → 打开 DateTimePickerPanel（kind=deadline）
  → 用户选择日期/时间/重复规则
  → 确认 → 插入 {{deadline:iso|recurrence}}
```
