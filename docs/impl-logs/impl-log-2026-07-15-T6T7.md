## T6 · DateTimePickerPanel — 完成 ✅

### 文件
- `src/components/DateTimePickerPanel.vue`
- `src/composables/useDateTimePickerPanel.ts`

### 面板功能
- **日期选择**：`input[type=date]`，聚焦时自动 focus
- **时间选择**：`input[type=time]`，可选
- **星期标签**：选中日期旁显示"周一"/"周二"等
- **重复规则**：下拉 none/daily/weekly/monthly/yearly
- **快捷日期**：今天 / 明天 / 下周 按钮
- **实时预览**：底部显示格式化后的日期文本 + 重复说明
- **键盘**：Enter 确认，Escape 取消

### 渲染模式
`<Teleport to="body">` + `position: fixed`（与 SlashCommandMenu 相同）
z-index: 1100（高于 slash menu 的 1000）

### 样式
与项目 CSS 变量（`var(--bg-base)`、`var(--accent)` 等）保持一致；暗色主题适配

### useDateTimePickerPanel 组合函数
- `visible` / `position` / `kind` / `initialIso` / `initialRecurrence` — computed 引用 store
- `open(payload)` — 填充 store 并让 visible=true
- `close()` — 设置 visible=false

### useDateRefClickListener 组合函数
- 监听 `dateRefClick` 自定义事件
- 从 `event.target.getBoundingClientRect()` 计算锚点 `{x, y}`
- 调用 `onClick(payload, position)` 回调（由外部传入 open）
