# CoMind 人工功能回归测试计划

> 版本：v1.0
> 日期：2026-11-20
> 状态：活跃
> 适用范围：全量核心功能人工回归（发布前 / 大改动合并前）
> 形态：可执行验收清单——每条含前置、步骤、预期、优先级，执行人照单点验即可

---

## 1. 目的与边界

**目的**：在自动化测试（vitest / Playwright）之外，用人工走查覆盖「需要人眼与手感判断」的部分——布局对齐、焦点与滚动连续性、拖拽落位、跨块选区、两态切换、暗色可读性、数据零丢失。

**不覆盖**：单元级逻辑（由 vitest 负责）、接口协议与同步冲突算法、性能基准（见 `tests/performance-benchmark.spec.ts`）。

**依赖**：本计划只断言「用户可观察的行为」，不重复断言 ADR 内部实现。规格真源仍是 `docs/adr/` 与 `CONTEXT.md`。

## 2. 判定口径与退出标准

### 2.1 优先级定义

| 级别 | 定义 | 示例 |
| --- | --- | --- |
| **P0** | 阻断级：数据丢失、崩溃、核心链路不可用、静默错误结果 | 剪切搬移后内容消失；表格合并后对齐串位；撤销撤销不掉 |
| **P1** | 功能级：功能可用但行为偏离规格，或需绕过才能继续 | 折叠后切页状态丢失；筛选脏标不出现 |
| **P2** | 体验级：视觉、文案、动画、间距、暗色弱底 | 圆角不一致；置灰提示文案不具体 |

### 2.2 判定规则

- 预期与实际不符即判 **失败**，不因「看起来不影响使用」而放过——记录后降级，不自行销案。
- 任何**内容/结构/字段值丢失**一律 P0，即使可手动重建。
- 首屏白屏、控制台未捕获异常、`invoke`/WASM 报错弹窗 → P0。
- 与「非缺陷清单」（§4）重合的现象不记缺陷，按清单判定，避免误报淹没真问题。

### 2.3 退出标准（一轮回归可宣布通过的条件）

1. 全部 P0 用例 100% 通过（允许 0 条失败、0 条未执行）。
2. P1 用例通过率 ≥ 95%，未通过项已录入缺陷表并标注影响面。
3. 无未关闭的 P0 缺陷；P1 缺陷已评估是否阻塞发布。
4. 全程无数据丢失；测后重启应用，抽查 5 个页面内容与字段值完整。
5. 缺陷表填写完整（含复现步骤与证据），可被第三方独立复现。

## 3. 环境与数据准备

### 3.1 环境矩阵

| 编号 | 形态 | 启动方式 | 用途 |
| --- | --- | --- | --- |
| ENV-1 | 桌面端（主） | `npm run tauri:dev` 或已构建安装包 | **所有用例的判定基准** |
| ENV-2 | 浏览器 dev | `npm run dev` | 仅用于布局/样式快速走查；查询块与任务中心**不作判定**（见 §4.1） |
| ENV-3 | Android | `npm run android:dev` | 可选；仅验 §A 导航与 §B 基础编辑 |

要求：ENV-1 的窗口尺寸不小于 1440×900；执行前清空控制台日志，便于捕获异常。

### 3.2 测试库隔离（执行前必须完成）

现有设置面板**没有「清空全部数据」能力**，隔离方式是切换工作空间路径：

1. 先做备份：设置 → 数据管理 → 「导出数据」（导出为 Markdown）。
2. 设置 → 数据管理 → 「工作空间路径」→「更改路径」→ 指向一个**新建的空目录**（如 `D:\comind-qa\2026-11-20`）→「确定」→ 重启应用。
3. 确认侧栏「最近」为空、页面库只有内置内容，即视为干净库。

> ⚠️ 若切换路径后旧数据被一并带入（说明该路径切换是迁移而非切换），**立即改回原路径**，改用「备份 → 在原库上建 QA- 前缀页面 → 测后用回收站清理」的方式。执行前由执行人确认该行为一次，勿假设。

### 3.3 固定数据集

按顺序搭建，后续用例按编号引用。搭建本身顺带验收了基础编辑能力。

| 编号 | 页面 | 内容要求 |
| --- | --- | --- |
| **DS-1** | `QA-基础`（普通页） | 1 个 h1 行、3 个普通文本块、1 个引用块、1 个分割线、1 个待办块、1 个带 2 层子块的父块（共 6 块） |
| **DS-2** | `QA-源`（普通页） | 一个 3 块子树，其中 2 块挂 `#任务` 并填 status/priority |
| **DS-3** | `QA-目标`（空白页） | 仅默认空根块 |
| **DS-4** | `QA-任务`（普通页） | 5 个块：status 分别为 Todo/Doing/Done 的组合，priority 覆盖 Urgent/High/Medium/Low；另加 1 块**只有 priority 无 status**；1 块**有 status 无内容**（空行） |
| **DS-5** | `QA-查询`（普通页） | 1 个查询块（默认表格视图）；1 个矩阵 tab（priority × status） |
| **DS-6** | `QA-表格`（普通页） | 4 列 × 5 行表格；含 1 处 2×2 合并；1 格加粗 + 背景色；1 格长文本（超 2 行软换行） |
| **DS-7** | `QA-媒介`（普通页） | 1 个图片块、1 个代码块（语言 Python）、1 处 `[[QA-基础]]` 引用、1 个外部链接、1 个 `@2026-11-20` 日期引用 |
| **DS-8** | `QA-删除`（普通页） | 临时页，仅用于 §I 回收站流程 |

数据集也可用「导入数据」（Markdown，合并模式）加速，但**先在空库导入 5 行小样**确认层级映射正确（`- ` 是否逐行成块），再导全量；映射不符时退回手工搭建。

## 4. 非缺陷清单（已知限制与既存基线）

执行中遇到以下现象**不记缺陷**，按此处判定。

| 编号 | 现象 | 判定 |
| --- | --- | --- |
| K-1 | 浏览器 dev（ENV-2）下查询块、任务中心的卡片列表恒为空态 | 已知限制，改在 ENV-1 判定 |
| K-2 | `cargo test -p comind-core --lib` 存在 4 条既有失败（issue #79） | 后端基线红，与人工回归无关 |
| K-3 | 同页「剪切 → 粘贴」的撤销需要两步；剪切后命名视图可能残留在孤儿命名空间 | 已知缺口，按 P2 观察项记录 |
| K-4 | 源页只有一个块时剪切它，会因「每页至少留一块」保留一个空块，目标页得到的是**新建副本**，原 `(( ))` 引用会断 | 已知例外，不判 P0 |
| K-5 | 表格块**不提供列宽拖拽**（菜单项「均分列宽」为 disabled，提示「列宽固定等宽，暂不支持调整」） | 设计如此；列宽拖拽只在查询/任务中心的表格视图存在 |
| K-6 | 自动化环境里窗口不在前台时剪贴板读写会失败 | 人工测试无此问题；仅影响脚本复现 |
| K-7 | 「书房」EPUB 导入与独立阅读窗口仅桌面端 | 浏览器/移动端无入口，非缺陷 |
| K-8 | 首次进入某页面时搜索结果/卡片列表短暂为空后填充 | 异步加载正常态；持续为空才算失败 |

## 5. 用例

编号规则：`TC-<模块>-<序号>`。每条标注 P0/P1/P2。「前置」若写 `DS-n` 表示已完成 §3.3 对应数据集。

### A. 应用外壳、导航与分屏

**TC-A01 · P0 · 冷启动可用**
- 前置：ENV-1 干净库
- 步骤：启动应用，观察首屏 3 秒
- 预期：侧栏 + 主区 + 顶栏正常渲染，无白屏、无错误弹窗；控制台无未捕获异常；默认打开「点滴」或上一次的页面

**TC-A02 · P0 · 侧栏五个导航项**
- 前置：无
- 步骤：依次点击侧栏「点滴」「页面库」「图谱」「任务」「标签」
- 预期：五项各自打开对应视图，当前项高亮；「点滴」条目显示今日日期与星期；「任务」文案为「任务」（非「任务中心」）
- 说明：侧栏只有「置顶」「最近」两个页面清单区，**没有**完整页面树——完整列表在「页面库」

**TC-A03 · P0 · 侧栏折叠**
- 步骤：按 `Ctrl+B`，再点顶栏 `.sidebar-floating-toggle`
- 预期：侧栏收起、主区铺满；悬浮按钮 title 在「展开侧边栏」/「折叠侧边栏」间切换；再次点击恢复；刷新后保持折叠状态

**TC-A04 · P0 · 新建 tab 并建页**
- 步骤：点 tab 条右侧 `+`（title「搜索或新建页面」）→ 输入 `QA-临时页` → 回车
- 预期：弹窗 placeholder 为「搜索页面，或输入名称新建…」，出现「新建页面「QA-临时页」」项；创建后新 tab 打开该页；侧栏「最近」出现该项

**TC-A05 · P1 · 单 tab 不可关闭**
- 前置：某 pane 只有 1 个 tab
- 步骤：悬停该 tab 的关闭按钮
- 预期：title 为「至少保留一个标签页」且点击无效；≥2 个 tab 时 title 为「关闭标签页」且可关闭

**TC-A06 · P0 · 两个分屏入口**
- 步骤：右上页面菜单 →「左右分屏」；拖动 `.pane-divider`；再打开该菜单 →「上下分屏」
- 预期：出现第二 pane 且复制当前 tab 视图；分隔条可拖动改宽（title「拖拽调整宽度」/「拖拽调整高度」）；再切方向后仍是 2 个 pane、仅布局变上下；不存在第 3 个 pane

**TC-A07 · P0 · Ctrl+Click 开对侧 pane**
- 前置：单栏，DS-1 含 `[[QA-基础]]` 引用
- 步骤：在活动 pane 中 `Ctrl+Click` 该页面引用
- 预期：自动拆为双栏；内容在**非活动** pane 打开，且该 pane 被激活（焦点/高亮转移到它）；URL 反映的是活动 pane

**TC-A08 · P1 · tab 拖拽排序**
- 前置：同一 pane 内 ≥2 个 tab
- 步骤：拖动 tab 到另一位置；切换页面后再回来
- 预期：顺序按拖拽结果变化；关闭按钮不会误触发拖拽

**TC-A09 · P1 · pane 菜单两条关闭项**
- 步骤：点 tab 条左侧「本栏操作」→「关闭其他标签」；重复 →「关闭本栏」
- 预期：前者只留当前 tab；后者关闭该栏（仅剩一栏时不可关到 0 栏）；不出现空白 pane

**TC-A10 · P0 · 全局快捷键**
- 步骤：依次按 `Ctrl+K`、`Ctrl+G`、`Ctrl+I`、`Ctrl+T`、`Ctrl+B`、`Alt+←`、`Alt+→`
- 预期：搜索面板、概念图谱、点滴、任务中心、侧栏折叠依次响应；`Alt+←/→` 在活动 pane 内前进后退；快捷键在输入框内不应误触发（除 `Ctrl+K` 外）

**TC-A11 · P1 · 主题切换与持久**
- 步骤：右上菜单切「深色」→ 刷新 → 切「浅色」→ 切「跟随系统」→ 改系统主题
- 预期：三种模式均即时全局生效；刷新后保持；「跟随系统」随系统切换

### B. 块编辑器核心

**TC-B01 · P0 · 输入与 Enter 拆分（不丢字）**
- 前置：DS-1，新建空块
- 步骤：输入 `abcdef` → 光标置于 `c` 与 `d` 之间 → 按 `Enter`
- 预期：拆为两块，两块文本合计恰为 `abcdef`（无字符丢失/重复）；新块为当前块的**兄弟**而非子块；焦点落在新块内

**TC-B02 · P0 · 行首 / 空行 Enter**
- 步骤：在块首按 `Enter`；再对一个空块按 `Enter`
- 预期：不产生内容丢失，不出现两块内容重复；空块按 Enter 后焦点留在可编辑块内（不跳到页面外）
- 备注：块首 Enter 是「上方插入空块」还是「拆分」以实现为准；本条只判「无内容损失 + 焦点不丢」，具体位置差异按 P2 观察记录

**TC-B03 · P0 · Backspace 合并**
- 步骤：把光标置于第二块行首 → `Backspace`
- 预期：第二块内容并入上一块末尾，第二块消失，光标停在拼接点；第一块内容不被覆盖

**TC-B04 · P0 · Tab / Shift+Tab**
- 前置：DS-1 的 3 个连续文本块
- 步骤：第二块按 `Tab` → 再按 `Shift+Tab`；对第一个块按 `Shift+Tab`
- 预期：Tab 后成为第一块的子块（缩进一级、出现层级线）；Shift+Tab 回到原级；第一个块 Shift+Tab 无效且不报错

**TC-B05 · P0 · ↑/↓ 跨块移动**
- 步骤：光标置于某块行首按 `↑`；行尾按 `↓`；在块中间按 `↑/↓`
- 预期：行首/行尾越界时才切换块（按先序顺序）；块中间只在文本内移动；切换后目标块可立即输入

**TC-B06 · P0 · ESC 退出并落库**
- 步骤：编辑某块 → `ESC` → 切到别的页面 → 返回
- 预期：退出编辑态；内容已保存，返回后完整可见

**TC-B07 · P0 · 折叠 chevron 与折叠范围**
- 前置：DS-1 的父块（有 2 层子块）；另建一块挂 `#任务` 并填字段（无子块）
- 步骤：悬停两个块 → 点 chevron 折叠
- 预期：有子块的块显示 `.bullet-chevron`；折叠后**子树与字段区一起隐藏**（字段带不残留）；无子块也无字段行的块不显示 chevron，且不可被置为折叠

**TC-B08 · P0 · 折叠状态持久**
- 步骤：折叠一个块 → 切页 → 返回；再刷新应用
- 预期：返回后仍折叠、刷新后仍折叠（`format.collapsed` 已落库）

**TC-B09 · P0 · 块类型渲染**
- 步骤：依次用 `/h1` `/h2` `/quote` `/code-block` `/divider` `/todo` `/numbered` 设置类型
- 预期：各类型渲染样式正确；切页返回后类型保持；`/divider` 不产生可输入的空块残留

**TC-B10 · P0 · 斜杠菜单定位与过滤**
- 步骤：在页面中部输入 `/`；输入 `head`；按 `Esc`；输入 `/query` 后观察
- 预期：菜单锚定在光标下方（**不得出现在视口左上角**，历史缺陷）；分组标题 + 主文案 + 副文案渲染正常；过滤实时生效；`Esc` 关闭且不插入字符；无匹配时显示「无匹配命令」

**TC-B11 · P1 · 模板插入**
- 步骤：斜杠菜单中进入模板子视图（标题「我的模板（点击使用）」）→ 选一个内置模板
- 预期：块按模板层级展开；来源标记显示 `[内置]` 或 `[我的]`；`{{cursor}}` 落点处光标就位；日期变量为今天

**TC-B12 · P0 · Ctrl+A 两次升级块全选**
- 步骤：在某块内按一次 `Ctrl+A`；再按一次
- 预期：第一次选中本块文本；第二次升级为块级全选（整块高亮，不仅是文本）；`Esc` 或点击他处可退出

**TC-B13 · P0 · 块全选后删除无残留**
- 步骤：块级全选 → `Delete` → 立刻点击页面空白处 → 再点入任意块
- 预期：内容按语义清空；**不残留紫色/高亮选区带**；无幽灵选中导致下次输入被覆盖

**TC-B14 · P1 · 保存失败提示**
- 步骤：制造一次写入失败（如工作空间目录改为只读路径后编辑）
- 预期：块左侧出现红点 + 错误底色，悬停有提示，点击可重试；恢复目录后重试成功、红点消失

### C. 块树操作：拖拽、多选、跨块选区

**TC-C01 · P0 · 拖拽落位与手柄**
- 前置：DS-1
- 步骤：按住父块的 `.block-bullet` 拖动 → 悬停到另一块的**上半部** → 放下；重复悬停下半部、左侧操作区
- 预期：落位指示线覆盖**整块外框（含子树）**，不是仅首行；上半部=前一个兄弟、下半部=后一个兄弟、左侧=子块；被拖块拖拽中呈半透明

**TC-C02 · P0 · 禁止拖入自身子树**
- 步骤：把父块拖到它自己的子块区域
- 预期：拒绝落位（无指示线或松手无变化）；父块与其子树结构不变

**TC-C03 · P1 · 拖拽后顺序持久**
- 步骤：调整 3 个块的顺序 → 切页 → 返回 → 刷新
- 预期：顺序在切页与刷新后都保持（无回弹、无乱序）

**TC-C04 · P0 · Ctrl+Click 块多选**
- 步骤：在块**内容区**内 `Ctrl+Click` 两块；再在**内容区外**（缩进区/行尾空白）`Ctrl+Click` 两块
- 预期：两个位置都能加入选中集合；选中块显示选中底色；再次 `Ctrl+Click` 取消该块

**TC-C05 · P0 · 多选删除与整体撤销**
- 步骤：选中 3 个块（其中一个是带子块的父块）→ `Delete` → `Ctrl+Z`
- 预期：删除时子树一并消失；一次撤销全部恢复（结构与内容一致）

**TC-C06 · P1 · 折叠块的复制含全子树**
- 步骤：折叠父块 → 选中 → 复制 → 粘贴到页面底部 → 展开新块
- 预期：新块子树完整（折叠状态不外泄为「复制时丢掉隐藏子块」）；新块 id 与原块不同

**TC-C07 · P0 · 跨块文本选区**
- 步骤：从 A 块文字中部按下鼠标拖到 B 块文字中部（拖动距离 > 4px）
- 预期：出现连续跨块高亮，**不出现两段错位/单块高亮**；拖过行尾时选区自动吸附到行首/行尾

**TC-H09 · P1 · 外部链接与日期引用**

### I. 其它成块功能

**TC-I01 · P0 · 图片块**
- 步骤：`/image` 上传 → 悬停工具条逐项：放大查看、复制图片、添加描述、裁剪、替换图片、删除图片、左/中/右对齐 → 拖四角改尺寸
- 预期：各操作生效；放大查看为灯箱且 `Esc` 可关；裁剪态有「取消」「确认裁剪」；尺寸与对齐在切页后保持

**TC-I02 · P0 · 代码块**
- 步骤：`/code-block` → 切换语言（Plain Text/JavaScript/TypeScript/Python/Go/Rust/SQL/Bash/JSON/HTML-CSS）→ 开「自动换行」→「复制」→ 点「折叠代码块」
- 预期：语法高亮随语言变化；复制后按钮文案变「已复制」；折叠可展开；语言选择切页后保持

**TC-I03 · P0 · 全局搜索**
- 步骤：`Ctrl+K` → 输入中文关键词 → 清空再输入英文 → 输入乱码
- 预期：分组「页面」「内容」结果正确、命中词高亮；`↑/↓` 选择、`Enter` 打开、`Esc` 关闭；无结果显示「未找到相关结果」；空输入显示「输入关键词开始搜索」

**TC-I04 · P0 · 回收站全流程**
- 步骤：删除 `QA-删除` → 回收站「恢复」→ 再次删除 → 「删除」→ 确认「永久删除页面」（提示「此操作不可撤销」）→ 用历史链接打开已删页
- 预期：恢复后内容完整；永久删除后列表消失；打开已删页出现「页面已在回收站中」+「恢复页面」/「忽略」；两步确认缺一不可

**TC-I05 · P1 · 设置面板五个分区**
- 步骤：依次进入「外观」「编辑器」「数据管理」「通知」「关于」
- 预期：外观含主题（浅色/暗色/跟随系统）+ 字体大小（较小/默认/较大/更大）；数据管理含工作空间路径（更改路径/恢复默认/打开目录）+ 导出/导入数据 + 自动同步（开关/同步间隔/立即同步）；通知含总开关与三类提醒 + 免打扰时段；关于显示 `comind v0.1.0`

**TC-I06 · P1 · 通知铃与面板**
- 步骤：造一个今天到期的 deadline 块 → 等调度 → 点铃铛 → 「全部已读」→ 对一条用「稍后提醒」（10 分钟/30 分钟/1 小时/明天）→「删除」
- 预期：有未读时显示角标（>99 显示 `99+`）；面板按 今天/昨天/M月D日 分组；各操作即时反映；空态「暂无通知」

**TC-I07 · P1 · 导出 / 导入往返**
- 步骤：数据管理「导出数据」→ 检查文件 → 在原库「导入数据」（合并模式）导入该文件
- 预期：导出包含全部页面与块；导入为合并语义（不覆盖、不重复建页）；导入后内容可正常编辑

**TC-I08 · P2 · 暗色全量扫视**
- 步骤：切深色，把 §B–§H 里出现过的浮层各打开一次（块菜单、斜杠菜单、日期选择器、行内格式工具条、表格选区浮层、字段设置弹窗、tab 菜单）
- 预期：无不透明白底；弱底色在 hover 时不被吞掉（按钮仍可辨识）；文字对比度足够；弹层不被裁剪

**TC-I09 · P2 · 窗口与顶栏**
- 步骤：拖动顶栏、点最小化/最大化/关闭（Tauri 环境）
- 预期：顶栏 48px 内可拖动窗口；三个窗口控件行为正确；顶栏控件不重叠；右上控件组在窄窗口下不换行错位
